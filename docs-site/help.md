# Help

## Ask questions or get help

Open a [discussion or issue on the GitHub repo](https://github.com/diegoeis/obsidian-conditional-properties/issues) — that's the primary channel for support on this plugin.

## Bug reports

Submit new issues on [the GitHub repo](https://github.com/diegoeis/obsidian-conditional-properties/issues). Before you submit a bug report:

1. Update to the latest version of the plugin and restart Obsidian.
2. Make sure the bug can be reproduced with other community plugins disabled.
3. Search [open issues](https://github.com/diegoeis/obsidian-conditional-properties/issues) to make sure it hasn't been reported before.
4. Include your rule configuration (Settings → Conditional Properties → Export settings) and a description of what you expected vs. what happened.

## Feature requests

Submit new requests on [the GitHub repo](https://github.com/diegoeis/obsidian-conditional-properties/issues). Search [open issues](https://github.com/diegoeis/obsidian-conditional-properties/issues) first to make sure it hasn't been requested before.

For general Obsidian feature requests unrelated to this plugin, use the [Obsidian Forum](https://forum.obsidian.md/) instead.

## Privacy

All processing happens locally. No data collection, no external requests — this plugin never sends your vault's content anywhere.
